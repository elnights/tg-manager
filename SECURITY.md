# Security policy

## Supported versions

Security fixes target the latest release in the 0.5.x line and the default
branch. Earlier versions are unsupported. This CLI requires Node.js 24+.

## Private reporting

Private vulnerability reporting is enabled for this repository. Submit reports
through the [private vulnerability reporting form](https://github.com/elnights/tg-manager/security/advisories/new),
also available under Security → Advisories → Report a vulnerability.

Include the affected version, impact and a minimal synthetic reproduction. Do not
open a public issue containing vulnerability details, credentials, sessions or
account data. Omit secrets and private account content from the report as well.

For scanner scope, exclusions and local review, see [docs/security.md](docs/security.md).
